# Indian Airlines Report - Power BI Dashboard

## Overview
Analyzed Indian Airlines flight data in Power BI to understand ticket price trends and visualized the insights in an interactive dashboard.

## Tools Used
- Power BI
- Power Query for Data Cleaning
- DAX

## Dataset
- File: Indian_Airline_Dataset.xlsx
- Total Records: 300K+

## Key Insights
- Vistara has the highest Max Ticket Price
- Mumbai and Bangalore routes have the highest Total Price
- Business Class Average Price is much higher than Economy Class
